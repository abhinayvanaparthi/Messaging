Frontend → Route → Middleware → Controller → Database → Response
🔹 routes → Entry point for requests

This is where the request first reaches.

Example: router.post("/login", loginUser);

This means: If a request comes to /login, call loginUser.

So this file is just a map of URLs to functions.

It does not contain business logic.

🔹 middleware → Security or pre-processing

This runs before controller.

Example: router.get("/", protect, searchUsers);

Here: protect runs first.

Its job: Check token, Verify user, Attach user info., This keeps your controller clean.

🔹 controllers → Main logic (brain)

This is where the real work happens.

Example: exports.loginUser = async (req, res) => { ... }

This:
✔ Reads request
✔ Checks database
✔ Executes logic
✔ Sends response.

🔹 models → Database blueprint

These define:
👉 How data is stored.

Example: const User = mongoose.model("User", schema);

This ensures: Structure, Validation, Relationships.

🔹 config → System setup

For: DB connection, Environment setup.
